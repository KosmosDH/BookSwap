# Описание дипломного проекта

## Тема

**«Разработка веб-приложения для обмена книгами между пользователями»**

## Цель

Разработать многопользовательское веб-приложение, позволяющее публиковать книги, находить подходящие объявления и организовывать обмен с помощью заявок и чата.

## Задачи

1. Проанализировать предметную область.
2. Спроектировать клиент-серверную архитектуру.
3. Спроектировать реляционную базу данных.
4. Реализовать REST API.
5. Реализовать JWT-авторизацию и роли.
6. Создать адаптивный frontend.
7. Реализовать заявки, избранное, чат и уведомления.
8. Добавить административную модерацию.
9. Контейнеризировать приложение.

## Почему проект подходит для диплома

По объёму он сопоставим с интернет-магазином: каталог, пользователи, роли, фильтры, изображения и админ-панель. Дополнительно присутствует собственная бизнес-логика обменов, чат SignalR, Redis и система репутации.

## Что демонстрировать

1. Вход под Анной.
2. Каталог и фильтры.
3. Создание книги с изображением.
4. Входящую заявку от Максима.
5. Принятие заявки и изменение статуса книг.
6. Чат в реальном времени в двух браузерах.
7. Уведомления.
8. Жалобу и её обработку под администратором.
9. Swagger.
10. Запуск всех сервисов через Docker Compose.

## Возможные улучшения

- карта и расчёт расстояния;
- подтверждение email;
- refresh-токены;
- рекомендации книг;
- полнотекстовый поиск;
- мобильное приложение;
- автоматическое заполнение по ISBN;
- email/push-уведомления;
- история аудита действий администратора.
