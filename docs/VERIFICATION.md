# Проверка сборки

Перед упаковкой проекта выполнены следующие проверки:

- `npm run build` — production-сборка React/TypeScript завершена успешно;
- `npm audit` — известных уязвимостей зависимостей не обнаружено;
- синтаксический разбор всех C#-файлов — ошибок синтаксиса не обнаружено;
- проверка JSON, XML (`.csproj`) и `docker-compose.yml` — файлы корректно разбираются;
- проверена согласованность маршрутов frontend, REST API и SignalR;
- ZIP-архив проверяется командой `unzip -t` после упаковки.

## Ограничение среды проверки

В среде, где формировался архив, не установлены .NET SDK и Docker. Поэтому здесь нельзя было выполнить фактическую команду `dotnet build` или поднять весь стек через `docker compose`. Для воспроизводимой полной проверки в проект добавлен GitHub Actions workflow `.github/workflows/ci.yml`, а локальный запуск выполняется через `docker compose up --build`.
